# Chrome Web Store listing copy

## Name

Rosé Pine — Afterglow

## Summary

A calm, modern Chrome theme with deep Rosé Pine surfaces and vivid, playful accents.

## Detailed description

Bring a quieter, more focused atmosphere to Chrome with Rosé Pine — Afterglow. Deep plum surfaces keep the browser chrome comfortably dark, while rose, iris, gold, pine, and foam accents add warmth without visual noise.

Highlights:

- A dark, cohesive toolbar and omnibox
- Clear contrast between active and inactive tabs
- A spacious new-tab background with crisp editorial linework
- Dedicated colors for inactive windows and incognito browsing
- Readable white bookmark labels
- No scripts, permissions, tracking, or data collection

Afterglow is designed for people who want a dark browser that feels considered rather than purely black.

Rosé Pine is created by the Rosé Pine project. This community theme uses its palette with attribution and is not represented as an official Rosé Pine release.

## Suggested listing fields

- Primary language: English
- Category: Themes
- Visibility for first review: Private or Unlisted, then Public after verification
- Homepage/support URL: use the public repository URL once it is ready

## Single purpose

Apply a cohesive Rosé Pine color palette and new-tab background to the Chrome browser interface.
