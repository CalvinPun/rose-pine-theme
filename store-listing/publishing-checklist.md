# Publishing checklist

## Package

- [ ] Run `python3 tools/build_theme.py`
- [ ] Confirm the manifest version is higher than the last uploaded version
- [ ] Upload `dist/rose-pine-afterglow-chrome-theme.zip`
- [ ] Confirm the package contains only the manifest and referenced PNG assets

## Store listing

- [ ] Paste the name, summary, and detailed description from `listing-copy.md`
- [ ] Keep `release-notes.md` handy for the version notes or announcement copy
- [ ] Select English and the Themes category
- [ ] Upload `store-icon-128.png`
- [ ] Upload `promo-small-440x280.png`
- [ ] Upload `promo-marquee-1400x560.png` for optional marquee consideration
- [ ] Upload at least one 1280×800 screenshot; both prepared screenshots are recommended
- [ ] Add a public homepage/support URL when available

## Privacy and policy

- [ ] Complete every Privacy practices disclosure as described in `privacy-practices.md`
- [ ] Confirm the item requests no permissions and collects no data
- [ ] Add the single-purpose statement
- [ ] Include the Rosé Pine attribution from `third-party-notices.md`
- [ ] Review the listing for accurate, non-repetitive metadata

## Final review

- [ ] Test the unpacked theme in normal, inactive-window, and incognito states
- [ ] Check the new-tab artwork at common window sizes
- [ ] Confirm screenshots contain no personal tabs, bookmarks, email addresses, or profile information
- [ ] Start with Private or Unlisted visibility if you want a final live-install test
- [ ] Submit for review, then monitor the dashboard for asset or policy feedback
